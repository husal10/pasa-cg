# Max-pressure signal control under detector faults

SUMO simulation code, raw results and analysis scripts for two papers:

- **ITSC 2027**: H. A. Idris and G. Cabri, *When a Phase Goes Blind: Detector Faults, Opposing-Arm Aggregation and the Cost of Guards in Max-Pressure Signal Control* (submitted).
- **IEEE T-ITS**: H. A. Idris and G. Cabri, *PASA-CG: phase-aware, consistency-gated sensor arbitration for max-pressure signal control under detector faults* (under review).

Each paper has its own tagged release of this repository (`v1.0-itsc2027`, `v1.1-tits`), archived on Zenodo.

## Contents

| Folder | What it holds |
|---|---|
| `pasa_itsc/` | Simulation package: network builder, fault injection, controllers, PASA-CG, sweep runner, checks |
| `pasa_itsc/cologne1/` | Cologne1 scenario files (third-party, see Licences) |
| `data/` | SUMO network and route files used by the sweeps (one folder per run window) |
| `runs/` | Windows batch files and the generator that launched the sweeps |
| `results/` | Raw results: one `all_results.json` per scenario, plus the per-cell files written during the runs |
| `tables/` | Per-episode tables built from `results/` (inputs to the analysis scripts) |
| `analysis/` | Statistics and figure scripts: `itsc2027/` for the conference paper, `tits/` for the journal paper |
| `tools/` | Episode audit script used after each sweep |

Result folders:

| Folder | Sweep |
|---|---|
| `results/results_v2` | Main grid sweep (both demand profiles, three demand levels, four fault patterns) |
| `results/results_ablation` | PASA-CG ablations (symmetric grid, medium and high demand) |
| `results/results_emis` | Emission runs (key cells, SUMO emission device on) |
| `results/results_c1` | Cologne1 main sweep |
| `results/results_rev` | Additional sweeps: field fallbacks with oracle diagnosis (R1, R8), guards (R2, R3, R8), planning error (R4), thresholds (R5), extra fault types and fault windows (R6), clip exemption (R7), diagnosis delay (R9) |

## Requirements

- SUMO 1.24 (the results were produced with Eclipse SUMO 1.24.0 on Windows 11), with `SUMO_HOME` set so that `traci` and `sumolib` can be imported
- Python 3.10 or later
- `pip install -r requirements.txt`

## Running a scenario

```
python -m pasa_itsc.main verify --net-dir data/net_sym
python -m pasa_itsc.main run-sweep --network grid2x2 --demand-profile symmetric ^
    --demand-level medium --fault-pattern phase_symmetric --fault-severity high ^
    --controllers std_mp_q pasa_max_mp pasa_cg_mp --fault-modes NONE HZ ^
    --n-seeds 10 --net-dir data/net_sym --output-dir results_new/example
python -m pasa_itsc.main demo --controller pasa_cg_mp --fault HZ --fault-pattern phase_symmetric
```

(`^` continues a line in the Windows command prompt; use `\` in bash.) The full option list is in `python -m pasa_itsc.main run-sweep --help`. Every `all_results.json` records the settings it was run with, so any scenario in `results/` can be rerun with the same options. The commands for the additional sweeps are in `runs/run_rev_w*.bat` (generated by `runs/make_bats.py`). Finished cells are skipped, so an interrupted sweep can be restarted.

## Reproducing the tables and figures

From the repository root:

```
python analysis/tits/analyse.py results tables
python analysis/extract_rev_episodes.py results/results_rev tables/rev_episodes.csv
python analysis/extract_c1_episodes.py results/results_c1 tables/c1_episodes.csv

cd tables
python ../analysis/tits/analyse_rev.py
python ../analysis/tits/analysis_revision.py . . out_extra
python ../analysis/itsc2027/conf_stats.py
python ../analysis/itsc2027/conf_figures.py ../figures/itsc2027
cd ..

python analysis/tits/figures_v2.py tables figures/tits
python analysis/tits/figures_cologne1.py results figures/tits tables
python analysis/tits/figures_sustainability.py results figures/tits
python analysis/tits/figures_revision.py tables figures/tits
python analysis/tits/fig_pasa_cg_flow.py figures/tits
python analysis/itsc2027/fig_conf_network.py data/net_sym/grid2x2.net.xml figures/itsc2027
```

| Paper | Item | Script | Output |
|---|---|---|---|
| ITSC 2027 | Fig. 1 (network and fault patterns) | `analysis/itsc2027/fig_conf_network.py` | `fig_conf_network` |
| ITSC 2027 | Fig. 2 (fault map), Fig. 3 (aggregation), Fig. 4 (guards) | `analysis/itsc2027/conf_figures.py` | `fig_conf_faultmap`, `fig_conf_aggregation`, `fig_conf_guards` |
| ITSC 2027 | Table I and the numbers in the text | `analysis/itsc2027/conf_stats.py` | `tables/conf/out/F1_*`, `F2_*`, `F3_*` |
| T-ITS | Main figures | `analysis/tits/figures_v2.py` | `fig_headline_*`, `fig_heatmap_*`, `fig_ablation`, `fig_detection`, `fig_fairness_*` |
| T-ITS | Cologne1 | `analysis/tits/figures_cologne1.py` | `fig_c1_*`, `c1_tests.csv`, `c1_summary.csv` |
| T-ITS | Emissions | `analysis/tits/figures_sustainability.py` | `fig_sus_*`, `sustainability_*.csv` |
| T-ITS | Guards and diagnosis delay | `analysis/tits/figures_revision.py` | `fig_rev_guards`, `fig_rev_diagdelay` |
| T-ITS | PASA-CG flow chart | `analysis/tits/fig_pasa_cg_flow.py` | `fig_pasa_cg_flow` |
| T-ITS | Confirmatory tests, ablation | `analysis/tits/analyse.py` | `confirmatory_total_delay.csv`, `ablation_total_delay.csv`, `summary_*.csv` |

The primary outcome is network total delay in vehicle-hours, `time_loss * n_trips / 3600` per episode. Seeds are paired across controllers and fault conditions.

## Code versions

Three code versions produced the results (see the papers). Each `all_results.json` stores a SHA-256 hash of the package source, the SUMO version and the platform under `provenance`. For this release the comments, docstrings and console messages were tidied and the unused plotting module was removed; the simulation code is otherwise unchanged. A test run of the release against the source that produced the last sweeps (hash `485adb78846c...`) gave identical episode results, but the hash of the released source differs from the recorded ones.
